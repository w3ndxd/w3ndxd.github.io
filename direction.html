Direction: where I see myself

At HZ the first two years are broad. At the end of year 2 I choose a track: Software Engineering or Applied Data Science & AI. After that I do a minor and an internship in that track. I looked into both, using the HZ website and what I learned in my first weeks of programming.

My direction: Software Engineering

What do you do in this field? Build software that works, keeps working and can be changed later. The work goes from requirements and design, to building with Git, testing with code reviews, and releasing and maintaining.
Which skills are important? Programming (for example Java, JavaScript or Python), SQL, Git, testing, Agile and teamwork.
Example functions Software engineer, web developer, cloud engineer
Why does this appeal to me? I like building things and I learn best by doing. The math in it, logic and algorithms, suits my structured way of thinking. And AI also has to be built and kept running as software.

Compared to Applied Data Science & AI

Topic Software Engineering Applied Data Science & AI
Main question How do I design, build and maintain software that works? What can data tell us, and what smart solutions can I make with it?
Typical result An app or system that people use An analysis, a model or a dashboard that supports a decision
Math Logic, discrete math, algorithms Statistics, probability, linear algebra, calculus
Example project A web shop where customers can order and pay A model that predicts when a machine will break down

The two are closer than they look: both start with programming, and a model is useless until software puts it inside an app. My love for math also pulls me toward data and AI, so I do not want to decide on expectations alone. My first year is my test: I choose Software Engineering if I enjoy Programming Basics, Object Oriented Programming and Web Application Development the most, and Data Science if I prefer Foundations of Data and Data Science Basics.

Future me

In four years I work as a software engineer at a technical company, for example one that builds simulation software or software for devices. I work in a small team and talk with clients about what they really need. I write clean code, test it and use my math to make programs faster and more reliable. My internship taught me to work with real clients. I plan every week, but now I know when something is good enough.

My route

  1. This year: pass my first year with all 60 EC (see my goals).
  2. End of this year: decide my next step, at HZ or at a university. I have wanted to study in the Netherlands since high school, especially at TU Delft, so I will check the admission requirements and talk to my student career coach first.
  3. Year 2 and 3: choose my track, then do a minor and an internship in it.
  4. After my studies: a career in a technical field where I program and use math.
