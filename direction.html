Direction: where I see myself

The first two years at HZ are broad. During year 2 I choose a track: Software Engineering (SE) or Data Science (DS).

Software Engineering compared to Data Science

Topic Software Engineering Data Science
Main question How do I design, build and maintain software that works and can be changed later? What can data tell us, and which smart solution (including AI) can I build with it?
How the work goes Collect requirements, design, program, test, release and maintain, in sprints with a team. Follow the CRISP-DM cycle: understand the business and the data, prepare the data, build a model, evaluate it and deliver it to the client.
Skills and tools Object-oriented programming, design patterns, refactoring code smells, unit tests, Git with branches, a CI pipeline, containers and cloud hosting. Python, cleaning data and handling missing values, splitting data into train and test sets, judging models with metrics, data visualisation and reporting.
Math Logic, algorithms and discrete math. Statistics, probability, linear algebra and calculus.
Typical result An app or system that people use. An analysis, a model or a dashboard that supports a decision.
Example functions Software engineer, web developer, cloud engineer, team lead. Data scientist, data analyst, machine learning engineer.
Example project A web shop where customers can order and pay. A model that predicts when a machine will break down, or the energy use of a region.

My picture and my choice

The two directions are closer than they look: both start with programming, and a model is useless until software puts it inside an app. My strength in math pulls me toward data science, but my interest in how computers work and my wish to build things pull me toward software engineering. For now I lean toward Software Engineering, because I like building things and learn best by doing.

I do not want to decide on expectations alone, so my first year is my test: I choose Software Engineering if I enjoy Programming Basics, Object Oriented Programming and Web Application Development the most, and Data Science if I prefer Foundations of Data and Data Science Basics. Before the choice, my student career coach gives information about the tracks, and I will talk to him or her first.

Future me

In four years I work as a software engineer at a technical company, for example one that builds simulation software or software for devices. I work in a small team and talk with clients about what they really need. I write clean code, test it and use my math to make programs faster and more reliable. My internship taught me to work with real clients. I plan every week, but now I know when something is good enough.
